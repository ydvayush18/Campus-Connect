# Neofilx
https://neural-nexus-81.preview.emergentagent.com/?utm_source=share
Role & Goal: Act as an expert frontend engineer, creative technologist, and UI/UX designer specializing in spatial computing, immersive web experiences, and futuristic interfaces (think Minority Report meets Apple Vision Pro). Build a fully functional, high-fidelity, futuristic 3D frontend concept for a streaming platform called "NEOFLIX: Horizon 2050".

Tech Stack Requirements:

Framework: React.js (with Next.js App Router) or Vite.

3D & Animation Engine: Three.js / React Three Fiber (R3F) combined with Framer Motion for smooth spatial transitions.

Styling: Tailwind CSS with custom glassmorphism, neon glow effects, and dynamic backdrop filters.

Icons & Assets: Lucide React icons, Unsplash/TMDB placeholders for imagery.

Core Features & Architecture:

Spatial Cinematic Hero Section (The Holographic Stage):

Instead of a flat banner, feature a central interactive 3D floating portal/card for a headline title (e.g., Interstellar: Odyssey Edition).
* Users can drag, rotate, or tilt the card in 3D space using mouse movement or touch gestures (gyroscope support).
* Include ambient background particles and a dynamic audio-reactive neon grid floor.

Multi-Dimensional Carousel / Orbit Browse:

Implement a curved, circular, or depth-stacked carousel for genres rather than a flat horizontal row.

Categories to feature: Cyberpunk Noir, Quantum Sci-Fi, Deep Space Documentaries, Holographic Thrillers, and Alternate Realities.

Use real, iconic movies for data realism (e.g., Blade Runner 2049, Interstellar, Matrix Resurrections, Dune: Part Two, Arrival).

Immersive Detail Modal (Neural Stream View):

When a movie card is clicked, it expands outward seamlessly in 3D space toward the user.

Display a holographic preview pane with cast information, a simulated neural synopsis, interactive 3D asset tags, and a glowing "Initiate Stream" action button.

Futuristic HUD & Navigation:

A sleek, translucent floating sidebar or bottom dock with glowing micro-interactions.

Include status widgets like "Quantum Connection: 10Tbps", local stellar time, and an AI search assistant bar ("Ask Nexus to find mind-bending sci-fi...").

Design Vibe: Dark mode dominant with deep obsidian blacks, accented by vibrant neon cyan, electric violet, and laser-white text. Subtle scanlines, chromatic aberration on hover, and premium glassmorphism.

Output: Provide clean, modular code components, state management logic for the 3D interactions, and instructions on how to install dependencies (three, @react-three/fiber, @react-three/drei, framer-motion, tailwindcss).
